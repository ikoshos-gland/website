Feeling the Kernel
A visual note on Gaussian processes

A function isn't a fixed line — it's a distribution you can shape. Drag a slider and watch the prior breathe.

Mert Koca 2026 · 06 · 23·8 min Compute Interactive

Gaussian processes sound intimidating until you see one move. The core idea is almost playful: instead of fitting one function to your data, you keep a whole cloud of plausible functions, and let the data narrow the cloud. Everything else is bookkeeping over that cloud.

01 The intuition

Before any data, a GP is defined entirely by its kernel — a function that says how related two points are. The most common one, the RBF kernel, says: points that are close should have similar values, and that similarity decays smoothly with distance.

note to selfThe length scale ℓ is the only knob that ever confused my students. Showing it as a slider fixed that in one afternoon.

Formally, the covariance between two inputs $x$ and $x'$ is

$$k(x,x') \;=\; \sigma^2 \,\exp\!\left(-\,\frac{\lVert x - x' \rVert^2}{2\,\ell^{2}}\right)$$

Two knobs: the amplitude $\sigma$ sets how far functions wander, and the length scale $\ell$ sets how quickly they wiggle. The figure below draws three functions straight from this prior. Move the sliders and feel what each parameter does.

02 On the cluster

gp_fit.pypython
def rbf(x, xp, sigma, ell):
    d2 = (x[:, None] - xp[None, :]) ** 2
    return sigma**2 * jnp.exp(-d2 / (2 * ell**2))  # the kernel above

“A kernel is just a hypothesis about smoothness — and the best way to test a hypothesis is to let someone drag it.”
